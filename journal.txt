Journal Format Guide (Immutable)
--------------------------------
Purpose:
- Maintain a chronological, prompt-scoped record of development actions and rationale.
- Provide quick traceability from instructions to filesystem changes.
Usage and Content Rules:
- Treat this guide as read-only; future sessions must not alter this section.
- For each prompt, record the exact prompt text on a single line beginning with `Prompt:`.
- Under each prompt entry, use leading `-` bullets for every file or directory that was created or modified in response.
- For each file/directory bullet, indent nested `-` bullets (two spaces) describing the specific sections or actions (2-10 bullets), focusing on what changed and why.
- Reference paths relative to the project root.
